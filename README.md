# Grappling OFP

Приложение для учета ОФП и борьбы подростка 14–15 лет.

Два режима: «Только дома» и «Дом + зал». В режиме «Дом + зал» силовые во вторник и четверг в 16:00. Борьба Пн–Пт 19:00–20:20; в субботу схватки с 10:00, в воскресенье отдых.

Откройте index.html в браузере или включите GitHub Pages: Settings → Pages → Deploy from a branch → main / (root) → Save.

История хранится в localStorage только текущего браузера, без синхронизации устройств. Есть экспорт CSV, резервная копия JSON и импорт. Данные несовершеннолетнего не должны попадать в публичный репозиторий.

Программа требует проверки тренером по ОФП подростков. Никаких максимальных весов или подходов до отказа.
