# Grappling OFP

Мобильный журнал ОФП и борьбы для подростка 14–15 лет. Программа силовой подготовки должна быть согласована с тренером; без максимальных весов, работы до отказа или тренировки через боль.

## Режимы и расписание

- «Только дома» и «Дом + зал».
- Зал во вторник и четверг около 16:00 в смешанном режиме; борьба Пн–Пт 19:00–20:20.
- В субботу схватки с 10:00, зал не запланирован. В воскресенье отдых.
- Одна общая дата для ОФП, борьбы и отмены; день недели определяется автоматически.
- Период 8 недель; неделя 7 облегчённая.

## Отмена борьбы

Откройте блок «Если борьбы в выбранный день нет». Укажите самочувствие и был ли зал. Приложение предложит лёгкую/полную тренировку или отдых с учётом ранее сохранённой ОФП за день. После занятия отметьте **фактически** выполненные подходы и **фактические** минуты. При отдыхе записывается 0 минут.

Отмена борьбы хранится как отдельное событие, а не как проведённая тренировка. На одну дату нельзя одновременно сохранить проведённую борьбу и её отмену, либо две отмены. Чтобы исправить статус, удалите ошибочную запись из истории.

Приложение не заменяет тренера и не учитывает всю нагрузку на ковре автоматически. При боли или выраженной усталости предпочтителен отдых и консультация взрослого/тренера.

## История, экспорт и прогресс

История в `localStorage` данного браузера. **Синхронизации между телефонами нет.** Перед очисткой браузера сделайте резервную копию JSON. Импорт JSON заменяет весь журнал после подтверждения. CSV нужен для таблиц, JSON для восстановления.

Поля техники и боли относятся к самооценке. После трёх занятий с подтверждённой техникой, без боли и с невысокой усталостью программа может **предложить обсудить** усложнение отдельного упражнения с тренером. Упражнения и рабочие веса автоматически не меняются.

Демонстрации открываются на внешних ресурсах. Для упражнений без точного проверенного соответствия оставлены текстовые инструкции.

## Разработка и проверка

Статическое приложение: `index.html`; сторонний сервер и сборка не нужны. GitHub Pages публикуется из Actions. Перед развёртыванием запускаются регрессионные проверки:

```bash
node tests/smoke.cjs
```

Тестируются привязка даты, сохранение, отмена/замена борьбы, учёт фактических минут, восстановление старых записей, защита от повреждённых данных и воскресный отдых.

**Важно:** проход автоматических проверок не подтверждает визуальную корректность на каждом телефоне. Программа и техника требуют проверки квалифицированным тренером. Личные данные несовершеннолетнего не должны попадать в публичный репозиторий.
