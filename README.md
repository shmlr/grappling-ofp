# Grappling OFP · домашние тренировки

[Открыть приложение](https://shmlr.github.io/grappling-ofp/)

**Версия:** 2026-11-14 · программа DRAFT до согласования фактической нагрузки подростка с тренером.

Статическое приложение для ведения двух **раздельных** тренировочных направлений:

1. **Подросток 15 лет, грепплинг:** домашняя ОФП A/B, учёт фактически выполненных подходов, тренировок на ковре и отмен.
2. **Взрослый:** ежедневная зарядка 10–15 минут (обычная, короткая, восстановительная), журнал выполненных зарядок и обзор силовых A/B на 25–35 минут.

## Текущее решение владельца

На 14.11.2026 спортзал **временно не посещают**. Базовый режим ОФП: **дома**. Упражнения сочетают умеренную изометрию, динамическую силу и координацию.

Исторический режим «Дом + зал» убран из активного интерфейса, **но записи старого журнала с mode=mixed продолжают читаться и экспортироваться**. Хранилище подростка `grappling-ofp-v2` **не мигрирует и не стирается**.

[Источник методики и научные ограничения (в архиве)](https://github.com/shmlr/r01-project-archive/tree/main/projects/grappling-ofp).

## Для подростка

- Вместо автоматического назначения силовой нагрузки на каждый будний день используются **добровольно выбираемые** домашние тренировки A/B.
- Учитывайте фактическое расписание грепплинга, особенно тяжёлые схватки. При 5–6 интенсивных тренировках на ковре начните с **одной** домашней силовой тренировки в неделю; вторую добавляйте только при хорошем восстановлении и после согласования с тренером.
- **Суббота:** схватки (историческое время 10:00, актуальность проверить), дополнительная ОФП не предлагается.
- **Воскресенье:** отдых, дополнительная ОФП и сохранение борьбы отключены.
- **6 недель:** контроль техники, умеренной нагрузки и восстановления; программа сама не увеличивает рабочий вес. Удержания ориентировочно 10–20 секунд для подростка; силовые упражнения без отказа.
- Расписание и время грепплинга в приложении **не являются подтверждёнными текущими данными** и должны сверяться с тренером.
- Журнал отмены борьбы и её замены по самочувствию сохраняется. Если ОФП уже была в выбранную дату, приложение рекомендует отдых, а не вторую тяжёлую сессию.

## Для взрослого

- 15 минут: разминка 2 минуты, 2 круга по 6 минут (40 секунд на станцию + 20 секунд перехода), завершение 1 минута.
- 10 минут: разминка 2 минуты, 1 круг 6 минут, координация 1 минута, завершение 1 минута.
- 10 минут восстановительного режима: лёгкая ходьба, подвижность плеч и таза, Bird-dog и баланс.
- Отдельные силовые тренировки A/B: ориентир **2 × 25–35 минут в неделю**. В их дни обычная ежедневная зарядка заменяется восстановительной версией или разминкой, чтобы не дублировать силовой объём.
- Подписываются **только фактически выполненные** зарядки; минуты и усталость вводятся после выполнения. Можно исправить запись выбранной даты, подтвердив замену.

## Журналы, экспорт и ограничения

- Подросток: старое хранилище `grappling-ofp-v2`, старый экспорт/импорт JSON и CSV, совместимость со старыми записями.
- Взрослый: **отдельное** хранилище `grappling-adult-v1`, собственный экспорт/импорт JSON. Экспорт подростка не содержит данных взрослого и наоборот.
- Всё хранится **только локально в браузере**. Синхронизации между устройствами нет. Перед очисткой браузера экспортируйте **оба** JSON.
- Импорт каждого журнала заменяет только свой журнал после подтверждения.
- Если данные повреждены, запись блокируется до восстановления. Ничего автоматически не перезаписывается.
- Не загружайте личные данные несовершеннолетнего в публичный GitHub.
- Это инструмент самоконтроля, а не медицинский допуск и не замена квалифицированного тренера. Самоотчёт об отсутствии болей/травм не является медицинским заключением. Не выполнять упражнения через боль и с задержкой дыхания.

## Разработка

Статический сайт: `index.html`. GitHub Pages публикуется из GitHub Actions. Перед публикацией запускаются:

```bash
node tests/smoke.cjs
npm install --no-save --no-package-lock playwright-core@1.55.0
node tests/layout.cjs
```

Smoke-тесты проверяют разграничение журналов, ручной выбор A/B, сохранение даты/времени, отмену борьбы, старые записи и защиту от повреждённых данных. Chromium-проверки оценивают пять ширин экрана.

**Важно:** успешные автоматические тесты не означают медицинскую валидацию программы. Действующее расписание борьбы до сих пор [Unverified].
